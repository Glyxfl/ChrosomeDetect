# ChrosomeDetect · 染色体图像分析与人工复核

本地网页工作台，串联模型预标注、辅助定位、人工复核、批量处理、质量一致率、染色体识别指标和结构化结果导出。

```text
原始图片（单张/批量）
  → 质量模型预分级 → 人工复核
  → 染色体簇检测 / 原图定位 → 人工复核
  → MI / 非 MI / 不可判读识别 → 人工复核
  → 簇内具体染色体候选定位 → 人工复核
  → 离群分数 / 原图高亮 → 确认、修正或驳回 → 结构化导出
```

## 启动

```text
python -m pip install -r workbench/requirements.txt
python -m workbench.server --port 8766
```

浏览器打开 <http://127.0.0.1:8766>。Windows 原工作区也可使用 `启动统一分析工作台.cmd`。

模型文件需单独配置；缺少权重会明确反馈。质量模型可先以 `python -m workbench.bootstrap_quality` 初始化一个合成数据实验模型，实际效果仍需真实人工标注数据验证。模型、原始图片、人工标注、数据库与历史结果不进入源码仓库。

## 主要能力

- 辅助定位：点击结果返回原图，定位到簇及具体染色体候选；保留唯一编号、原图坐标、所属簇和轮廓，疑似离群红色高亮。
- 人工复核：确认、修正、驳回，记录复核人、原因、时间；保留原始模型预标注与变更前后快照，上游修改自动使后续结果失效。
- 指标：质量模型与人工等级一致率，簇与单条候选的 precision / recall / F1，单张机器耗时及批量均值；缺少完整人工真值时显示不可计算。
- 批量：多图上传、按阶段排队、失败隔离、等待人工关卡、任务与批次持久化。
- 交付：JSON / CSV / ZIP，包含原图、高亮图、裁剪、预标注、最终结果、审计与任务耗时记录。
- 训练：检测、分裂期分类、质量分类与离群特征基线的配置、分组数据校验、训练和独立测试入口。

## 当前边界

质量初始化模型只用合成图训练，不能宣称真实数据准确率。单条染色体可接入外部 YOLO 检测/分割权重，未配置时使用连通区域候选；粘连和碎片需人工修正，候选数不等于真实染色体数。离群分数是图像特征复核提示，不是生物学异常概率。指标基于人工复核符合性，独立测试效果需另外准备测试集。

网页支持普通图片；SDPC/SDQC 巨幅切片统一网页任务尚未实现，原工作区保留原有流式离线切块入口。服务当前面向本机研究使用，没有多用户鉴权。历史工作区的数据与工具保留在本地，不纳入本次源码发布。
