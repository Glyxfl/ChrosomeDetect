# ChrosomeDetect · 染色体图像分析与人工复核

以 **SDPC 原始切片** 为输入的本地网页工作台：导入后自动识别染色体簇，再串联模型预标注、辅助定位、人工复核、批量处理与结果导出。无需预先导出 PNG/JPEG。

```text
SDPC 原始切片（单个/批量；分块上传或本地路径免复制）
  → 自动金字塔分块检测 / 跨块合并 / L0 无损染色体簇导出
  → 簇图质量模型预分级 / 原切片定位 → 人工复核与簇确认
  → MI / 非 MI / 不可判读识别 → 人工复核
  → 簇内具体染色体候选定位 → 人工复核
  → 离群分数 / 原图高亮 → 确认、修正或驳回 → 结构化导出
```

## 启动

```text
python -m pip install -r workbench/requirements-sdpc.txt
python -m workbench.server --port 8766
```

浏览器打开 <http://127.0.0.1:8766>。Windows 原工作区也可使用 `启动统一分析工作台.cmd`。

模型文件需单独配置；缺少权重会明确反馈。质量模型可先以 `python -m workbench.bootstrap_quality` 初始化一个合成数据实验模型，实际效果仍需真实人工标注数据验证。模型、原始图片、人工标注、数据库与历史结果不进入源码仓库。

## 主要能力

- 辅助定位：切片概览支持缩放、平移并按需读取原生金字塔区域；点击簇图可回到 SDPC L0 坐标定位。具体染色体候选保留本地和全切片坐标、所属簇、轮廓与唯一编号。
- 人工复核：确认、修正、驳回，记录复核人、原因、时间；保留原始模型预标注与变更前后快照，上游修改自动使后续结果失效。
- 指标：质量模型与人工等级一致率，簇与单条候选的 precision / recall / F1，单张机器耗时及批量均值；缺少完整人工真值时显示不可计算。
- 批量：多个 SDPC 自动提簇、8 MiB 分块续传、扫描断点继续、簇图阶段批量复核与推理，失败任务单独显示。
- 扫描：可选 L3 粗筛 → 候选区域 L1/L2 精检，或 L1/L2 全量覆盖；最终均从 L0 原始数据读取跨瓦片完整区域并无损输出，不放大低分辨率图。快速模式的全片检出率尚待人工标注验证。
- 交付：JSON / CSV / ZIP，包含原图、高亮图、裁剪、预标注、最终结果、审计与任务耗时记录。
- 训练：检测、分裂期分类、质量分类与离群特征基线的配置、分组数据校验、训练和独立测试入口。

## 当前边界

质量初始化模型只用合成图训练，不能宣称真实数据准确率。单条染色体可接入外部 YOLO 检测/分割权重，未配置时使用连通区域候选；粘连和碎片需人工修正，候选数不等于真实染色体数。离群分数是图像特征复核提示，不是生物学异常概率。指标基于人工复核符合性，独立测试效果需另外准备测试集。

网页主入口只接受 `.sdpc`。SDK 已在本机 Windows / Python 3.10 对真实 SDPC 验证，其他系统需验证原生库兼容性；不以修改后缀宣称支持 SDQC。质量和识别指标目前以提取出的簇图及其候选为范围，不代表全切片漏检率。局部 ROI/调试任务明确标为非全片。服务当前面向本机研究使用，没有多用户鉴权。原始切片、权重、SDK 二进制及业务标注不纳入源码发布。
